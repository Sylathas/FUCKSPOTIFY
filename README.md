These are more technical specifications of the website:

## Architecture

### Frontend (Next.js + React)
- **Framework**: Next.js 15.4.4 with React 19.1.0
- **Styling**: Tailwind CSS 4
- **TypeScript**: Full type safety
- **State Management**: React hooks for local state
- **API Integration**: Spotify Web API SDK

### Backend (FastAPI + Python)
- **Framework**: FastAPI with Uvicorn
- **Database**: SQLite with SQLAlchemy
- **Authentication**: OAuth 2.0 for Spotify and Tidal
- **Background Tasks**: Async processing for long-running operations
- **Caching**: In-memory and persistent caching systems

For complete transparency, I've coded it through manual coding, the online Claude platform (mostly with Sonnet 4 and Opus 4.1), and the Cursor IDE agent.


### Planned Features
- **Other platforms**: Full transfer support for Apple Music and Soundcloud
- **Email Notifications**: Optional email alerts for transfer completion
- **Batch Operations**: Improved handling of large libraries

### Technical Improvements
- **Database Optimization**: Enhanced caching strategies
- **Performance Tuning**: Faster transfer speeds
